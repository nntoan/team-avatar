I rewrote `README.md` to describe what shelf actually does. The old version was all adjectives. The new one covers what the library is, how to run it, the `paginate` and `pageCount` API, how `loadConfig` merges its sources, and what is still unfinished. Nothing is committed.

**Changes in substance:**
- **There's a bug in `paginate`, and the README now says so.** It returns one item fewer than `perPage` on a full page. When I ran it, `paginate(items, 1, 3)` gave `[1, 2]`. The cause is the `- 1` in the `slice` end at `src/paginate.js:4`. `npm test` also fails on `first page holds perPage items` (2 pass, 1 fail). I didn't fix it because you asked for docs only. It's a one-character fix if you want me to make it.
- **The config section is new.** The old README never mentioned `loadConfig`. There's now a table of the three settings, their defaults and their `SHELF_*` variables. It notes that a missing `shelf.json` is skipped but invalid JSON throws (`src/config.js:9`), and that `SHELF_PORT=abc` becomes `NaN`. I ran both of those.
- **`slugify` is listed as unfinished.** It only throws `not implemented` (`src/slug.js:2`).
- **Setup imports straight from `src/`.** `package.json` has no `main` or `exports`, so an "install it from npm" step wouldn't work.
